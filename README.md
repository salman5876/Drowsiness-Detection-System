# Drowsiness Detection System

A real-time drowsiness detection system that uses a webcam and AI model to monitor facial features and eye movements to detect signs of drowsiness. The system is built using OpenCV, a pre-trained neural network, and a Flask-based GUI for easy interaction.

## **Features**
- Real-time drowsiness detection through webcam
- Alerts when drowsiness is detected
- User-friendly GUI with Flask integration
- Scalable AI model for accurate face and eye detection

---

## **Tech Stack**
- Python
- Flask
- OpenCV
- TensorFlow/Keras (for AI model)
- HTML, CSS, JavaScript (for GUI)
